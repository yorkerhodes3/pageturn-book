Production comparison

Payload weight

V2 semantic book

~74 KB

Approximately 27 KB gzip for reader CSS/JavaScript plus 46 KB gzip for all 17 semantic chapters.

Legacy fixed pages

~9.10 MB

Approximately 24 KB gzip for runtime code plus 9.07 MB of 46 already-compressed WebP page images.

Complete-book reduction

~99.2%

V2 runtime code is only about 2 KB gzip larger. The major saving comes from semantic text replacing raster pages—not from avoiding SVG, because the legacy pages are WebP images.

Measurements use the production What Is Ethical AI? fixture and modeled gzip sizes from the built Pages artifact. Shared HTML shell overhead is excluded from both sides.
