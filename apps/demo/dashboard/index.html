Delivery status

Capability matrix

Capability Status Current evidence
Semantic HTML and stable anchors Implemented Native text, direct chapter URLs, references, and citation-safe anchors.
Open-book presentation Implemented Outer cover, inner cover, title/imprint leaves, page fans, running folios, and continuous CSS curl.
Front matter and contents Implemented Publication record, title page, thesis, disclaimer, and a multi-page linkable table of contents.
Page-edge grab and turn Implemented Mouse, touch, cancel/reverse gestures, arrows, and keyboard navigation.
Continuous fold geometry V3 supported PageTurn projects every shelf publication through StPageFlip-derived geometry. V2 remains available only for migration comparison while performance hardening continues.
Semantic chapter openings V3 implemented Manifest chapters begin fresh leaves with a separate chapter-number label and prominent title. Narrative chapters receive a desktop opening initial; Works Cited remains an undecorated reference list.
Bounded chapter-window loading V3 implemented Stable state retains the active chapter and immediate neighbors. Chapters open on the right by default; four measured short-chapter books use continuous flow without forced blank versos. A turn briefly retains its complete source and destination spreads.
Durable V3 reading location V3 implemented Book, edition, chapter, and source anchor survive reloads and responsive repagination. Explicit URLs outrank saved resume state, and browser Back/Forward restores semantic locations rather than screen-page numbers.
All-publication semantic ingest V3 implemented All 20 report-model sources, the 542-term Cyber Dictionary, and Plurality's 30 CC0 chapters build into immutable semantic manifests and open from the shelf. Editorial parity and upstream export hardening remain.
Publication figure treatments V3 implemented; catalog migration open Ethical AI maps three lossless figures and Plurality maps 11 explicitly licensed figures with Off, On-page, and Pop-out modes. Default Pop-out loads no image until activation; production manifest integration remains open.
Responsive physical pagination Implemented 99 spread screens or 221 phone screens, with zero internal page scrolling.
Adjustable book typography Implemented V2 and V3 share per-publication 80%–130% controls and repaginate around the current source anchor without clipping.
Publication bookshelf Implemented 22 lazy-loaded volumes with metadata-driven leather or cloth bindings and V3 geometry actions.
Share current reading location Implemented V2 and V3 use native Web Share when available, with clipboard fallback. V3 can explicitly include selected text and always uses the canonical book, chapter, and source anchor.
Legacy facsimile fallback Implemented Any shelf volume opens its immutable production page manifest.
Footnotes and endnotes Source dependent Plurality chapter notes are linked from canonical Markdown. Ethical Tech report sources expose Works Cited but generally lack mapped footnote callouts.
Right-to-left physical book mode Future RTL semantic scroll reading remains available. Physical book mode is disabled until sheet order, gestures, origins, and curl geometry are fully mirrored and tested.
Local comments and annotations V3 beta Selected quotes and optional notes remain edition-scoped in this browser, can be revisited or deleted, and export locally as Markdown. Synchronization remains prohibited.
Collaborative comments Future Requires identity, moderation, privacy, and a service boundary after local annotations.
Bookmarks, contents, search, and offline cache V3 beta; offline planned V3 has hierarchical contents, demand-loaded search, edition-scoped bookmarks, and visible resume restart. Bounded offline caching remains planned.
Low-end mobile turn profile Measured p95 reaches 54.9 FPS at 1x and 54.1 FPS at 2x CPU throttle with no long tasks. The 4x profile reaches 38.5 FPS and remains below promotion gate.

V2 compatibility book

~79 KB

Approximately 33 KB gzip for reader CSS/JavaScript plus 46 KB gzip for all 17 semantic chapters.

Legacy fixed pages

~9.10 MB

Approximately 27 KB gzip for runtime code plus 9.07 MB of 46 already-compressed WebP page images.

Initial-transfer reduction

~99.6%

V3 initially serves only a bounded semantic chapter window. Static hosting still retains every chapter, while the browser avoids downloading and retaining the rest until requested.

Measurements use the production What Is Ethical AI? fixture and gzip-equivalent sizes from the built Pages artifact. The V3 initial figure includes catalog-enabled assets, manifest, and the first two chapters after adjacent prefetch; route HTML is excluded consistently with the existing runtime-plus-content comparison.
